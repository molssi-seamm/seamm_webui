===========
seamm_webui
===========

``seamm_webui`` is a from-scratch, SPA-based web dashboard for SEAMM
(FastAPI backend + React/Vite frontend). It runs alongside the older
``seamm_dashboard``, pointed at the same datastore, rather than replacing
it -- submit, list, monitor, and manage SEAMM jobs and projects from a
browser, with real per-user login for anything reachable beyond your own
machine.
